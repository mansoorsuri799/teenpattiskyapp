# Teen Patti Sky (teenpattiskyapp.com.pk)

Next.js site for **Teen Patti Sky** APK guides in Pakistan — download, deposit, withdraw, PC, and SERP-focused blogs.

## Stack
- Next.js App Router + TypeScript + Tailwind
- Domain: `https://teenpattiskyapp.com.pk`

## Develop
```bash
npm install
npm run dev
```

## Build
```bash
npm run build && npm start
```

## Key routes
- `/` Home
- `/download-teen-patti-sky`
- `/deposit-money-in-teen-patti-sky`
- `/withdraw-money-from-teen-patti-sky`
- `/teen-patti-sky-for-pc`
- `/blog` (+ 4 posts)
- `/sitemap-index.xml`, `/index.xml`, `/image-sitemap.xml`, `/robots.txt`
